# Project Review

## Project

**Name:** Dungeon Manager

**One Sentence Pitch:** Build and manage your own dungeon.


# 1. First Impression
Spend 10-20 minutes using the project without making changes.
- front menu doesn't have settings or exit game option
- game needs a tutorial for initial room building
- not enough gold at the start of the map
- I can see an enemy AI lair and should not be able too
- enemy attacks to fast
- ui is dated/still using the rust default

# 2. Story
Would I keep reading?
- no current story, should have a tutorial and intro

# 3. Does it Have Potential?
Ignoring its current state...
Could this become something great with more work?
- I think its got the bones of a dungeon manager, but is still a vertical slice for content.

# 4. Biggest Problems
- enemy attacks to fast and killed before doing any setup, initial wave slowdown and future saves larger gap

# 5. Best Parts
What already works well?
- the dungeon building is working correctly, you can dig out rooms and collect gold.

# 6. Next Goal
What is the **single most important milestone**?
- more gold on the map around the dungeon core so the initial setup is not slowed down

# 7. Content Notes (Optional)
Would this make an interesting YouTube video or livestream?
it might in the future but not now.
